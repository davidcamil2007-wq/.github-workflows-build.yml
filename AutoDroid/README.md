# AutoDroid v3

Um APK para os dois aparelhos.
- Celular: ícone "AutoDroid" (voz, notificações, hotspot).
- Kit: ícone "AutoDroid Kit" (painel de notificações flutuante sobre o Waze).

## Celular
1. Botões de CONFIGURAR (uma vez) e "ESCOLHER O BLUETOOTH DO CARRO".
2. Ao conectar no carro: o app liga o modo carro e avisa para ligar o hotspot.

## Kit
1. Conecte o Wi-Fi do kit no hotspot do celular.
2. Abra "AutoDroid Kit": botão 1 (sobreposição), botão 2 (ligar painel), TESTAR PAINEL.
3. Depois o painel liga sozinho quando o kit inicia.
