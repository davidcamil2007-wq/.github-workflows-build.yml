# AutoDroid v4 (sem voz)

Um APK para os dois aparelhos.
- Celular: ícone "AutoDroid" -> painel do carro (envia notificações e a lista de apps).
- Kit: ícone "AutoDroid Kit" -> tela principal estilo Android Auto.

## Celular
1. Botões de CONFIGURAR (uma vez) e ESCOLHER O BLUETOOTH DO CARRO.
2. Ligue o hotspot. ATIVAR PAINEL DO CARRO.
3. Para usar apps do celular no kit: ESPELHAR A TELA NO KIT (aceite "Tela inteira").

## Kit
1. Conecte o Wi-Fi do kit ao hotspot e abra "AutoDroid Kit".
2. MENU > Escolher apps da tela principal (apps do kit e do celular).
3. Toque num app do celular: ele abre no celular e aparece espelhado no kit.
